Location on this map

Browsers require a secure (HTTPS) connection before sharing your location, and this device serves over standard HTTP. You can always read coordinates by tapping anywhere on the map.

To enable GPS in Chrome (Android or desktop), allow this address once:

  1. Open a new tab and go to chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Enter http://nomad.local in the text field
  3. Set the flag to Enabled and choose Relaunch
  4. Return here and use the locate button again

Safari on iPhone and iPad has no equivalent setting; tap the map to read coordinates instead. This setting only affects your own browser.
