Nomad restarts, joins your network, and serves its library (plus DLNA and OPDS) to every device on it, with no captive portal. Nomad's screen shows the address it was given. If the network can't be reached, it falls back to hotspot mode on its own. Without auto-reconnect, unplugging and replugging always returns to hotspot mode; with it, hold the side button while Nomad boots to force hotspot mode. Tip: set an admin password before joining a shared network.

    Asking the card…
    How this works

    Nomad counts every card read and write and flags any that fail or are slow. Check the card reads a few hundred spots across the card, takes about 10 s and is safe while people are watching. Failed reads usually mean the card is wearing out.

    Cover thumbnails

    Checking…
    How this works

    Makes a small copy of every cover so the library grids load a few kilobytes per card instead of the full-size artwork. Detail pages keep the original. Progressive JPEGs can't be read by this board's decoder and are left as they are.

    Firmware

    Risky
    Asking Nomad…

    Updating restarts Nomad and stops whatever is playing. If the new firmware doesn't start, Nomad goes back to this one. Keep it plugged in while it updates.

    How this works

    Check nomadflash downloads the newest firmware for this board and needs WiFi Mode on a network with internet. Upload a file takes a .nomadfw saved from nomadflash and works offline. Firmware not signed by nomadflash or not made for this board is refused. After the restart, if the card, WiFi or pages fail within a minute, Nomad switches back. USB flashing from nomadflash always works.

    Backup

    How this works

    Saves the hotspot name and password, pages, theme, screen, lights and TV support to one file. The admin password and home WiFi aren't in it. Hotspot changes take effect after a restart.

    Support file

    Last crash--
    How this works

    One file with the firmware and board, memory, the log, card health, the last crash and the settings, passwords removed. Send it with a bug report. Nothing leaves Nomad unless you send it.

    After three crashes in a row, each within a few minutes of starting, Nomad starts in safe mode with indexing and TV support off. Start normally, or unplugging it, goes back to a normal start.
